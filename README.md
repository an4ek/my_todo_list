# My To-Do List ФИТ-231 Лебедева Анна

## 🎯 Функционал

 Базовая структура To-Do: список задач + форма/модалка для добавления.
 
 Карточка задачи содержит: чекбокс, название, кнопки редактирования и удаления.
 
 Добавление задачи через модальное окно с формой.
 
 Редактирование задачи — меняется название.
 
 Удаление задачи работает.
 Переключение темы (светлая/тёмная).
 Поиск по названию задачи (динамическая фильтрация списка).
 Использование Sass/Scss для стилей (структурировано).
 Код написан на Vanilla JS или jQuery (по выбору).
 Присутствует адаптивность (мобильный / десктоп).
 Работает отметка о выполнении задачи
